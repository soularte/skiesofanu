# Карточки ссылок

`npm run social:generate` создаёт 16 JPEG-карточек (по текущему содержимому сайта) в `public/social/` и карту маршрутов `src/generated/social.json`. Генерация читает заголовки и исходные изображения из контента, пропускает черновики и не включает незавершённые подборки. Размер — 1200×630, лимит — 300 000 байт. Исходные обложки не изменяются и не обрезаются.

Индивидуальные подписи для книг одного автора и поправки только для карточек задаются в `src/data/social.json`. Авторские ключи берутся из `src/data/authors.md`; текущие подписи сверены с обложками. Остальные книги используют обоих авторов сайта.

После изменения заголовков, обложек или добавления страниц запустите генерацию, просмотрите JPEG и выполните `npm run build`. Добавляйте в коммит JPEG, JSON-карту маршрутов и изменённые источники вместе. Генератор использует локальный Georgia (или DejaVu Serif/serif при отсутствии); на другой ОС перед коммитом проверьте переносы и шрифт. Готовые JPEG хранятся в Git, поэтому GitHub Pages и Netlify публикуют одинаковые карточки и не зависят от шрифтов сервера сборки.

Имя JPEG содержит хеш содержимого: новая версия получает новый адрес картинки. Это помогает обновлению изображений, но не гарантирует сброс кэша самой ссылки в соцсети.

BaseLayout использует карту только для OG/Twitter. Изображения в теле страниц и JSON-LD сохраняются. Для маршрута без карточки остаётся прежнее изображение; неизвестные размеры не объявляются. Для стандартной картинки используются реальные размеры.

После публикации проверьте прямые JPEG-адреса и настоящие превью главной, книги, цикла и статьи в Telegram и VK. Проверка сборки не заменяет этот шаг.

Описания книг берутся из shortDescription без пересказа. Для остальных страниц согласованные подписи задаются полем description в src/data/social.json. Генератор проверяет число строк и пересечение с блоком авторов.
