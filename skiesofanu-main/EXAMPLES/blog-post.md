# ─── Дата публикации ──────────────────────────────────────────────────────────
# Формат: ГГГГ-ММ-ДД (без кавычек!)
# Используется для сортировки (новые сверху) и отображения на карточке

# ─── Краткое описание (excerpt) ───────────────────────────────────────────────

# Также используется как meta description для SEO.

# ─── Теги ─────────────────────────────────────────────────────────────────────
# Массив тегов для категоризации. Отображаются как #тег на карточке.
# Рекомендуется 3-5 тегов. Пишите строчными буквами.
tags: [тег1, тег2, тег3, закулисье, процесс]

# ─── Обложка поста (необязательно) ────────────────────────────────────────────
# Путь относительно папки public/
# Рекомендуемый размер: 800×600px (соотношение 4:3)
# Если не указать — карточка будет без изображения.
# Поддерживаемые форматы: .jpg, .png, .webp, .svg
cover: "/images/blog/your-cover.jpg"

Вступительный абзац. Зацепите читателя — расскажите, о чём пойдёт речь
и почему это интересно. **Выделяйте** ключевые мысли.

## Первый подзаголовок

Основной текст секции. Здесь раскрываете тему.
Используйте *курсив* для акцентов и **жирный** для важного.

## Второй подзаголовок

Продолжение текста. Можно использовать списки:

- Первый пункт
- Второй пункт
- Третий пункт

Или нумерованные:

1. Шаг первый
2. Шаг второй
3. Шаг третий
