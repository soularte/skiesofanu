# Проверка исправления UI-01

29 октября 2026. Исправление выполнено локально в `src/components/Lightbox.astro`; публикация не выполнялась.

## Изменение

- Пока просмотр изображения открыт, остальные непосредственные дочерние элементы body становятся inert. Сохраняются и восстанавливаются их исходные состояния, включая уже существовавший inert.
- Tab/Shift+Tab циклически обходят видимые кнопки окна. Для одного изображения доступны только закрытие; скрытые стрелки не попадают в обход.
- При закрытии фокус возвращается к конкретному нажатому элементу. Для img/div используется временный tabindex=-1, который удаляется при уходе фокуса. В обычную Tab-последовательность новая остановка не добавляется.
- Исходное значение body.style.overflow восстанавливается, позиция страницы сохраняется.
- Сохранены оформление, подбор групп изображений, счётчик, перелистывание, Escape, закрытие по фону/крестику и совместимость вызова window.__openLightbox(images, index).
- Повторное открытие уже открытого окна не перезаписывает исходное состояние фона; пустой список изображений не открывает окно.

Это изменение UI-01. Перевод всех изображений в полноценные кнопки (UI-02), размеры точек, боковые зоны слайдеров и другие пункты аудита не выполнялись.

## Результаты

**32 из 32 сценариев страниц прошли:** все 16 страниц основного sitemap проверены на 390 × 844 и 1440 × 1000 CSS px. На 11 страницах есть доступные группы Lightbox; суммарно проверены 53 сочетания страницы, ширины и группы. Выполнены 955 программных проверок состояния DOM/фокуса/прокрутки в основном прогоне. Это число проверок, а не независимых пользовательских сценариев.

Проверялись обложки, промокарточки, персонажи, дополнительные материалы/карта и дипломы авторов, доступные при соответствующей ширине.

Проверки каждой группы:

- открытие, начальный фокус на закрытии, блокировка фона;
- Tab и Shift+Tab, включая переход через границу списка кнопок;
- перелистывание ArrowRight/ArrowLeft и кнопками, где изображений несколько;
- Escape, повторное открытие, крестик и реальный клик по затемнённому фону;
- touch-нажатие крестика на мобильной ширине;
- возврат фокуса к исходному элементу, очистка временного tabindex при blur;
- восстановление overflow, позиции прокрутки и исходных inert-состояний.

Проверки страниц включали отсутствие общего горизонтального переполнения, открытие/закрытие мобильного меню, работоспособность переключателей мобильных слайдеров и прокручиваемости настольных дорожек после закрытия, совместимость глобальной функции и отдельный сценарий с одним изображением. Прокрутка галерей проверяется с учётом scroll-snap: промежуточная позиция может законно привязаться обратно к первой карточке.

**Отдельно прошли 8 проверок:** настоящее mouse/touch-открытие обложки на двух ширинах, невозможность прокрутить фон колёсиком при открытом окне, возврат фокуса и восстановление прокрутки после закрытия. Результаты — `pointer-results.json`.

`npm run build` — успешно, 21 страница. `git diff --check` — успешно.

## Материалы

- `results.json` — окончательные результаты 32 сценариев страниц, все passed=true.
- `pointer-results.json` — дополнительный ввод мышью/touch и колесом.
- PNG в этой папке — вид открытого Lightbox на обеих ширинах; просмотрены мобильная и настольная версии обложки «Авиаторы».
- `check.mjs` и `check-pointer.mjs` — воспроизводимые браузерные проверки без дополнительных npm-зависимостей; нужен Node с WebSocket, Chrome с DevTools Protocol и локальная сборка.

## Повторный запуск

Из корня проекта:

```sh
npm run build
npm run preview -- --host 127.0.0.1 --port 4322
```

В отдельном терминале запустить изолированный Chrome (путь ниже для macOS):

```sh
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless --disable-gpu --no-first-run --no-default-browser-check --user-data-dir=/tmp/skies-lb-validation-chrome --remote-debugging-port=9334 about:blank
```

Затем:

```sh
node audits/ui-2026-10-29/lightbox-validation/check.mjs
node audits/ui-2026-10-29/lightbox-validation/check-pointer.mjs
```

При другом адресе сервера или CDP задать UI_BASE_URL / UI_CDP_URL. Запуск перезаписывает результаты и снимки этой проверки. Проверки используют исходный список 16 страниц из `../measurements.json`.

## Ограничения

Проверена производственная сборка через локальный Astro preview в Chrome на macOS. Мобильная ширина, touch-ввод и клавиатура эмулированы через CDP. Проверка на физическом iPhone/Safari, Android и в Firefox не выполнялась; полную гарантию для всех браузеров этот результат не даёт. Все прочие пункты первоначального UI/UX-аудита сохраняют свой статус.
