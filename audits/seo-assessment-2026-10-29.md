# Аудит индексации и Яндекс.Метрики

Дата: 29 октября 2026 года. Основной адрес: https://skiesofanu.ru/.

## Вывод

Технических блокировок индексации основных страниц не обнаружено. Все 16 URL опубликованного sitemap отвечают HTTP 200, имеют собственный canonical, уникальные title и description, не содержат meta noindex и X-Robots-Tag. Это подтверждает готовность к обходу, но не факт включения страниц в поисковый индекс.

Метрика №109339298 подключена и выполняется: в отдельном профиле Chrome загрузился tag.js с HTTP 200, отправился запрос просмотра страницы с page-url=https://skiesofanu.ru/ и признаком pv:1; после промежуточного 302 сервер сбора ответил HTTP 200. Следующий запрос также получил 200. Отображение визита в кабинете, фильтры и принадлежность счётчика без доступа к кабинету не проверены.

Главная обнаруженная проблема — неверный SSL-сертификат обоих зеркал .com. Перенос трафика со старого домена нельзя считать завершённым.

## Объём и доказательства

- Проверены живые robots.txt, sitemap-index.xml, sitemap-0.xml, все 16 URL sitemap, четыре /paths/, доменные варианты и случайный несуществующий URL.
- Для каждого HTML проверены HTTP-статус, canonical, robots, title, description, H1, наличие инициализации счётчика, синтаксис JSON-LD, наличие alt у изображений и ссылки на другие страницы сайта.
- Проверены исходники Astro, конфигурация публикации и аналитики. `npm run build` завершился успешно: 21 страница, включая 404 и четыре /paths/.
- Выполнена браузерная проверка главной через Chrome headless с отдельным временным профилем и сетевым журналом.
- `seo-pages-2026-10-29.json` содержит результаты обхода каждой страницы. `metrika-network-2026-10-29.json` содержит обезличенную сводку ответов Метрики; cookies и параметры идентификации не включены.
- Код сайта и настройки хостинга не изменялись.

## Метаданные и содержание

- У всех 16 основных страниц есть уникальные title и description. Пустых значений и дубликатов в этой выборке нет.
- Язык HTML — ru, присутствуют viewport, Open Graph и Twitter Card. Доступность и внешний вид всех социальных изображений отдельно не проверялись.
- JSON-LD синтаксически корректен. Обнаружены Organization, WebSite, ProfilePage, Article, Book, BookSeries и BreadcrumbList по типам страниц. Это не заменяет проверку требований расширенных результатов Google.
- У изображений проверенных страниц присутствует атрибут alt. Смысловое качество каждого описания вручную не оценивалось.
- На страницах «Авиаторы Его Величества» и «Маги Канверона» по два H1: название мира и название произведения. Рекомендуется оставить один основной H1, другой сделать H2 или обычным текстом. Это улучшение структуры, а не обнаруженный запрет индексации.
- В главном H1 имена авторов находятся внутри вложенных элементов; упрощённый анализатор в JSON вывел только прямой текст «Соавторский дуэт:». Не следует трактовать это как отсутствие имён в реальном заголовке.
- Описания некоторых книг очень короткие: например, у «Авиаторов» — «Цикл приключенческих романов в антураже дизельпанка». Полезно добавить имена авторов, завязку и сведения о чтении/покупке естественным языком.
- Общий meta keywords перегружен словами на двух языках. Не считать его инструментом обеспечения индексации; приоритет у содержания, понятных заголовков и ссылок.
- HTML страниц авторов составляет примерно 232 и 269 КБ до сжатия. Есть адаптивные изображения и lazy loading, но реальные Core Web Vitals, мобильное удобство и Lighthouse не измерены. Числовой балл скорости по этой проверке не выставляется.

## Аналитика

Счётчик задан в `src/data/site.md`, подключается общим `src/layouts/BaseLayout.astro`. В опубликованном HTML всех 20 проверенных содержательных страниц найдены одна инициализация и ID 109339298. Проверка выполнения в браузере проведена на главной; выполнение на каждой внутренней странице отдельно не измерялось.

Включены clickmap, trackLinks, accurateTrackBounce и webvisor. Наличие webvisor:true не доказывает наличие записей Вебвизора в кабинете. Повторные /watch-запросы после просмотра могут быть служебными событиями; сами по себе они не означают дублирование просмотров.

Показ баннера конфиденциальности не управляет запуском счётчика: Метрика стартует в head независимо от закрытия баннера. Это описание текущего поведения, не юридическая оценка.

Явных вызовов reachGoal в исходниках не найдено. Переходы по внешним ссылкам могут фиксироваться через trackLinks, а цели могут быть настроены в кабинете без кода. Проверить существующие цели в кабинете и при необходимости настроить переходы на ЛитРес, Автор.Тудей, ЛитГород, подписку на Telegram/VK. Покупку на внешнем магазине по одному клику нельзя считать подтверждённой.

GitHub Pages не применяет netlify.toml. На основном домене ограничивающий CSP в проверенных HTTP-заголовках отсутствует. Поэтому CSP из Netlify не объясняет непоступление данных с .ru. При будущей публикации на Netlify нужно заново проверить разрешённые адреса: в браузерном тесте Метрика обращалась также к mc.yandex.com, которого нет в текущем connect-src Netlify.

Если в кабинете нет визитов, проверить:

1. Открыт ли именно счётчик 109339298 и принадлежит ли он нужному аккаунту.
2. Диапазон дат, сегменты, фильтры, исключение собственных посещений и ограничения по доменам.
3. Появление тестового просмотра с .ru в отчётах. Аудит создал искусственный визит около 12:26 по Мадриду; часовой пояс отчёта может отличаться. Бот-фильтрация может исключить headless-визит.
4. Обычный браузер без блокировщика и отладчик https://skiesofanu.ru/?_ym_debug=2: нужный ID в Counters и PageView в Console.

Не следует менять рабочий ID или устанавливать второй счётчик, пока не проверены эти условия.

## Приоритет действий

1. **Высокий:** восстановить валидный сертификат для .com и www.com на обслуживающем их хостинге. Затем включить постоянный 301 на .ru с сохранением пути и UTM. Проверить оба HTTPS-зеркала и вложенные адреса. Локальная правка netlify.toml сама по себе сертификат не исправляет.
2. **Высокий:** в Google Search Console и Яндекс.Вебмастере подтвердить владение .ru, проверить отправку https://skiesofanu.ru/sitemap-index.xml, отчёты об индексировании и последние обходы. Проверить главную, профили авторов, каталог и ключевые книги через инспекцию URL; запросить переобход при необходимости.
3. **Высокий для аналитики:** сверить ID и фильтры в кабинете Метрики и подтвердить появление обычного тестового посещения. Веб-интеграция уже работает по браузерному тесту.
4. **Средний:** проверить/настроить цели переходов на книжные площадки и подписки, использовать UTM во внешних рекламных ссылках.
5. **Средний:** уточнить структуру H1 на двух страницах циклов и расширить короткие описания книг.
6. **После готовности содержания:** если /paths/ нужны в поиске, завершить их, дать уникальные описания и внутренние ссылки, затем согласованно снять noindex и исключение из sitemap. Сейчас запрет соответствует комментарию о незавершённых страницах; автоматически снимать его не нужно.
7. **Следующий этап:** измерить мобильные Core Web Vitals/PageSpeed; проверить отчёты расширенных результатов и внешние ссылки на книги. В данном аудите не проверялись все внешние магазины, каждый графический ресурс и история поискового трафика.
