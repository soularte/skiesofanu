# Пример: страница категории (paths)

Файлы категорий лежат в `src/content/paths/`. Каждый файл — это отдельная страница
"С чего начать знакомство", доступная по адресу `/paths/{имя-файла}/`.

---

## Структура файла

```markdown
---
# === Обязательные поля ===
title: "Название категории"        # Заголовок страницы
cover: "paths/имя-файла.jpg"       # Картинка для панели на главной (src/assets/images/paths/)
order: 1                           # Порядок отображения на главной (1 = первый)

# === Галерея обложек (горизонтальный скролл) ===
# Указываем slug книг из src/content/books/
# Для отдельных книг серии: "slug-серии:номер" (1-based)
books:
  - "aviatory:1"     # 1-я книга серии «Авиаторы» (Похищенное солнце)
  - "aviatory:2"     # 2-я книга серии
  - "danlin"         # Отдельная книга (не серия)
  - "kanveron"       # Обложка серии целиком

# === Карточки книг с описанием ===
# Каждая карточка показывает обложку + текст
featured:
  - book: "aviatory"                 # slug книги или "slug:номер"
    text: "Свой текст описания"      # Необязательно — если не указать, возьмёт из книги
  - book: "danlin"                   # Без text — описание берётся автоматически

# === Промо-карточки (горизонтальный скролл с увеличением по клику) ===
# Имя папки в public/cards/
cards: "Aviators"    # → читает все картинки из public/cards/Aviators/

# === Masonry-галерея (Pinterest-стиль, внизу страницы) ===
# Путь к папке в src/assets/images/
gallery: "gallery/mir-anu"   # → все картинки из src/assets/images/gallery/mir-anu/
---
```

## Тело статьи (markdown)

После `---` идёт обычный markdown-текст. В нём можно использовать:

### Текстовые ссылки

```markdown
Начните с серии [Авиаторы Его Величества](/books/aviatory).
Читайте также [блог](/blog/) и [об авторах](/about/).
```

### Картинки в тексте (с фиксированной шириной и увеличением)

Чтобы вставить картинку с возможностью открыть в полный размер:

```markdown
![Описание](/images/covers/aviatory.jpg){.img-preview}
```

Или через HTML для точной ширины:

```markdown
<img src="/images/covers/aviatory.jpg" alt="Авиаторы" class="img-preview" width="250" />
```

Класс `img-preview` делает:
- Фиксированную ширину (по умолчанию max-width: 300px)
- Скруглённые углы и тень
- Курсор «увеличить» и открытие в полный размер по клику (lightbox)

Для изменения размера используйте `width`:

```markdown
<img src="/images/covers/danlin.jpg" alt="Данлин" class="img-preview" width="200" />
```

### Картинки в ряд (`img-row`) с индивидуальной высотой

Если нужно несколько картинок в одну строку и задавать высоту каждой отдельно, используйте HTML-строку и `height` в каждом теге `img`.

```html
<div class="img-row">
  <img src="/images/covers/placeholder-v.jpg" alt="Вертикальное" height="300" />
  <img src="/images/covers/placeholder-h.jpg" alt="Горизонтальное" height="150" />
  <img src="/images/covers/placeholder-sq.jpg" alt="Квадратное" height="150" />
</div>
```

Как это работает:
- `img-row` — контейнер с flex, выравниванием по центру и переносом строк;
- `height="..."` задаёт высоту конкретной картинки в пикселях;
- ширина считается автоматически, пропорционально исходному размеру картинки;
- если все картинки в сумме шире контейнера, они переносятся на следующую строку;
- это работает только в виде прямого HTML внутри markdown, потому что `:::marker`/markdown не умеет задавать атрибуты картинки так же точно, как HTML-тег.

Важно: `height` задаётся в пикселях, а не в CSS-классах. Внутренний стиль `img-row img`/`img-preview` не должен переопределять этот параметр, иначе будет игнорироваться.

Рекомендуемый шаблон для такого блока:

```html
<div class="img-row">
  <img src="/images/covers/placeholder-v.jpg" alt="Вертикальное" height="300" />
  <img src="/images/covers/placeholder-h.jpg" alt="Горизонтальное" height="200" />
  <img src="/images/covers/placeholder-sq.jpg" alt="Квадратное" height="200" />
</div>
```

Если картинка слишком широкая для контейнера, она переносится на следующую строку. Это удобно, когда нужно показать разные пропорции: вертикальную, горизонтальную и квадратную.

### Маркеры для вставки компонентов

Компоненты можно вставить **в любое место** текста с помощью маркеров:

```markdown
Вступительный текст...

:::featured

Текст между карточками и книгами...

:::books

Ещё какой-то текст...

:::cards

:::gallery
```

**Доступные маркеры:**

| Маркер        | Что рендерит                                     | Откуда данные          |
|---------------|--------------------------------------------------|------------------------|
| `:::featured` | Карточки книг (обложка + описание)               | `featured:` в frontmatter |
| `:::books`    | Горизонтальный скролл обложек                    | `books:` в frontmatter    |
| `:::cards`    | Промо-карточки с увеличением по клику             | `cards:` в frontmatter    |
| `:::gallery`  | Masonry-галерея (вертикальные + горизонтальные)   | `gallery:` в frontmatter  |

**Важно:** маркер должен быть на отдельной строке, без пробелов перед ним.

Если маркеры не используются — все компоненты автоматически рендерятся после текста
в порядке: featured → books → cards → gallery.

## Полный пример файла

```markdown
---
title: "Мир Ану"
cover: "paths/mir-anu.jpg"
order: 1
books: ["aviatory:1", "aviatory:2", "aviatory:3", "aviatory:4", "danlin"]
featured:
  - book: "aviatory"
    text: "Главная серия — дирижабли, небесные пираты и приключения в стимпанк-вселенной."
  - book: "danlin"
    text: "Отдельная история в мире Ану. Можно читать независимо."
cards: "Aviators"
gallery: "gallery/mir-anu"
---

Добро пожаловать в мир Ану — вселенную дирижаблей, паровых машин и небесных приключений.

<img src="/images/covers/aviatory.jpg" alt="Обложка серии" class="img-preview" width="250" />

:::featured
```

## Где хранить файлы

| Что                     | Куда класть                              |
|-------------------------|------------------------------------------|
| Картинка для панели     | `src/assets/images/paths/`               |
| Картинки для masonry    | `src/assets/images/gallery/{имя-папки}/` |
| Промо-карточки          | `public/cards/{имя-папки}/`              |
| Картинки для вставки    | `public/images/` (любая подпапка)        |
| Обложки книг            | Берутся автоматически из данных книги    |
