# Шаблоны контента

Готовые примеры для создания нового контента на сайте.  
Скопируйте нужный файл в целевую папку, переименуйте и заполните.

| Файл | Что создаёт | Куда класть | URL |
|------|-------------|-------------|-----|
| `book-series.md` | Серия книг (цикл) | `src/content/books/` | `/books/<slug>` |
| `book-standalone.md` | Отдельная книга | `src/content/books/` | `/books/<slug>` |
| `blog-post.md` | Пост блога | `src/content/blog/` | `/blog/<slug>` |
| `lore-post.md` | Лор / доп. материал | `src/content/lore/` | `/books/<book>/lore/<slug>` |
| `author-page.md` | Страница автора | `src/content/authors/` | `/about/<slug>` |

## Как использовать

1. Скопируйте шаблон в нужную папку
2. Переименуйте файл (имя без `.md` станет slug → часть URL)
3. Заполните frontmatter (между `---`) — следуйте комментариям внутри
4. Напишите текст в body (после второго `---`)
5. Положите изображения в указанные папки

## Куда класть изображения

| Тип | Папка | Примечание |
|-----|-------|------------|
| Обложки книг | `src/assets/images/sp/` | 600×900px, 2:3 |
| Фото персонажей | `src/assets/images/characters/` | 400×600px, портрет |
| Фото авторов | `src/assets/images/authors/` | Квадрат или портрет |
| Обложки блога | `src/assets/images/blog/` | 800×600px, 4:3 |
| Иллюстрации лора | `public/images/lore/` | 1200×600px, широкоформат |
| Промо-карточки | `public/cards/<Имя>/` | Свободный размер |
| Видео (трейлеры) | `public/videos/` | .mp4 или .webm |

## Настройки сайта (data-файлы)

Единичные файлы конфигурации — не коллекции, шаблоны для них не нужны.  
Редактируйте напрямую, каждый файл прокомментирован внутри:

| Файл | Что настраивает |
|------|-----------------|
| `src/data/site.md` | Название, описание, аналитика, подзаголовки страниц, SEO-описания |
| `src/data/authors.md` | Портреты и био на `/about` |
| `src/data/links.md` | Соцсети, литпорталы, контакты |
| `src/data/news.md` | Плашка «В работе» на главной |
| `src/data/ui.md` | Все UI-строки: навигация, заголовки секций, aria-labels, тексты страниц |
| `src/data/first.md` | Блок «С чего начать» (вкл/выкл + заголовок) |
